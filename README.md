# UNDERWEARjanan

فروشگاه اینترنتی UNDERWEARjanan

## اجرا
- Node.js 20 یا جدیدتر
- دستور اجرا: `npm start`
- سرور از متغیر `PORT` استفاده می‌کند.

## انتشار روی Render
نوع سرویس: Web Service
Runtime: Node
Build Command: `npm install`
Start Command: `npm start`

## نکات امنیتی
- فایل `.env` و اطلاعات محرمانه را در GitHub بارگذاری نکنید.
- فایل `data.json` شامل اطلاعات سفارش‌ها است و نباید عمومی شود.
- برای محیط عملیاتی از پایگاه داده پایدار و پشتیبان‌گیری استفاده کنید.
